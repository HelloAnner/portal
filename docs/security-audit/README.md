# 安全与审计

## 功能定位

安全与审计用于保障门户统一认证、权限配置和子系统访问过程可追踪、可校验、可回溯。

## 安全要求

门户需要保证：

- 身份凭证不可伪造。
- 子系统只能信任门户签发或门户后端确认的身份上下文。
- 子系统访问凭证短时有效。
- 权限变更可及时生效。
- 高风险管理操作有审计记录。

## 审计事件

门户至少需要记录：

- 用户登录成功。
- 用户登录失败。
- 用户退出登录。
- 用户进入子系统。
- 子系统凭证签发。
- 子系统凭证校验失败。
- 用户权限变更。
- 子管理员身份变更。
- 系统入口配置变更。
- 子系统接入配置变更。

## 审计字段

审计记录至少包含：

- 操作时间。
- 操作人。
- 操作类型。
- 操作对象。
- 操作前数据。
- 操作后数据。
- 请求来源 IP。
- 用户代理。
- 操作结果。
- 失败原因。

## 安全边界

门户负责统一认证、统一授权和身份上下文签发。

子系统负责：

- 校验门户身份上下文。
- 执行业务侧权限判断。
- 记录自身业务操作审计。
- 在凭证无效时拒绝访问或跳回门户。

## 风险控制

需要重点控制：

- URL 参数伪造用户身份。
- 门户托管模式下，子系统仍允许绕过门户直接登录。
- 权限撤销后凭证仍长期有效。
- 子系统编码与门户登记不一致。
- 子系统误信任未签名或过期身份上下文。
