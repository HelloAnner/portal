# 系统目录

## 功能定位

系统目录用于管理门户中展示的子系统入口。它是用户进入 Northline、DocuMind 等系统的入口配置中心。

## 系统信息

每个系统至少需要配置：

- 系统编码。
- 系统名称。
- 系统描述。
- 系统图标。
- 系统分类。
- 入口 URL。
- 启用状态。
- 是否接入门户认证。
- 是否允许普通用户访问。
- 是否支持子管理员。

## 用户侧展示

门户根据用户权限展示系统目录。

普通用户只能看到自己有权限访问的系统。门户超级管理员可以看到全部系统及其配置状态。

系统卡片或入口建议展示：

- 系统名称。
- 系统说明。
- 当前用户身份，例如普通用户或管理员。
- 进入按钮。
- 权限不足提示或申请入口。

## 管理侧能力

门户超级管理员需要支持：

- 新增系统。
- 编辑系统信息。
- 启用或停用系统。
- 配置系统入口地址。
- 配置是否由门户托管认证。
- 配置系统支持的角色和权限声明。
- 配置系统管理员。

## 系统状态

系统状态至少包括：

- 启用。
- 停用。
- 接入中。
- 维护中。

停用或维护中的系统不应允许普通用户进入。
